UltiObserver
============

UltiObserver is an Android app for Ultimate observers. It helps track the game
state, score, pull timing, timeouts, caps, misconduct, event log, and shareable
post-game summary that would otherwise be split between a paper game card and a
stopwatch.

The app is Android-first and designed for phone use in portrait mode.

Documentation
-------------

The user documentation lives at:

<https://rmjarvis.github.io/UltiObserver/>

The docs cover installation, game setup, live-game workflows, timing cues,
misconduct, saved and archived games, privacy, troubleshooting, and planned
improvements.

Installation
------------

UltiObserver is currently in Google Play beta testing. To install it, request to
be added to the testing group. Ping @Mike Jarvis on the observer Discord, or
send an email to mikejarvis17 [at] gmail [dot] com.

Privacy
-------

UltiObserver does not have ads, in-app purchases, or user accounts. It does not
intentionally send your game data to Mike Jarvis or to any server operated by
UltiObserver.

The app stores your profile, settings, current game, and archived games locally
on your device. Android may include this app data in its normal device backup
system, depending on your phone and Google account backup settings.

Release builds use Firebase crash and diagnostic reporting to help debug
stability problems.

For more detail, see the [UltiObserver privacy policy](PRIVACY.md).
