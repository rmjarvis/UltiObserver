More Actions
============

The **More actions** menu has a number of less common operations that you may need
during a game, such as corrections and unusual game-management situations.

Update Game Setup
-----------------

**Update game setup** lets you change something from the initial setup after
the game has started. This reopens setup with the current game information
already filled in and lets you adjust whatever you need.

Typical reasons include:

* changing the display colors for one or both teams;
* updating coach, field captain, or spirit captain names;
* changing any rules that you set incorrectly before the game;

Field And Pull Controls
-----------------------

**Change pull prompts** lets you change which timing prompts you receive for pull
countdowns. As with the initial setup, you may choose either end, neither, or both.

**Flip field display** swaps which end is displayed on the top and bottom of the field
display screen. This only changes the display. It does not change the pulling
team, pulling end, countdown target, or pull-prompt target.

**Swap pulling team** changes which team is set to pull for the current point.
You can use this if you marked the initial pull wrong in setup to quickly correct which
team is pulling. This keeps the teams where they are on the field and only changes which
team is pulling.

Corrections
-----------

More Actions includes buttons to adjust various things about the current game state.
These let you fix errors or omissions made earlier in the game, which mean the app's
current recorded game state does not match what actually happened on the field.
As with any action, adjustments are undo-backed, so you can undo it if the adjustment
itself was incorrect.

**Adjust score** lets you change the current score.

**Adjust timeouts** lets you change the number of timeouts used by either team. In the
second half, you can adjust the number taken in the first half in case that matters for
a floater timeout.

**Adjust pull violations** lets you change the number of pull violations assessed to each team
in case you forgot to record one that your partner called, for instance.

**Adjust cards/techs** lets you change the number of cards and technical fouls assessed to
each team. You can also edit details about previous yellow and red cards if you later learn
more details about a player (e.g. their name) or want to record or change a reason for the card.

Game Summary and Event Log
--------------------------

**Game Summary** lets you view a game summary page for the current in-progress game.
Usually these are useful for completed games, but if you want to share the game summary so
far at halftime for some reason, this action lets you do that.

**Event log** shows a time-stamped list of all actions recorded so far in the game.
This lets you quickly review the order of events as you recorded them, perhaps to share
with your partner if you realize you disagree about the current state of the game.

Manual Halftime and Game End
----------------------------

**Start halftime** manually starts halftime at the current score. This might be useful if there
is no half cap, but the teams decide that it would be appropriate to take half earlier than the
normal halftime score.

**End game** manually ends the game at the current score. Normally the game ends automatically
when the score reaches the target score, taking any caps into account. But if the game ends
in an unusual manner (e.g. canceled for lightning), this lets you end the game directly.

Manual Caps
-----------

**Apply half cap now** applies the half cap immediately.

**Apply soft cap now** applies the soft cap immediately.

**Apply hard cap now** applies the hard cap immediately.

These could be useful if the tournament horn is slightly out of sync with your phone clock,
so the app doesn't think the cap applies quite yet, but the horn means it does.
