Profile
=======

.. figure:: screen-shots/Profile.png
   :class: phone-screenshot
   :target: _images/Profile.png
   :alt: Profile screen with observer name and avatar selection

The main thing to set on the profile screen is your name. When it is set, any new-game setup
pre-populates the first observer row with that name. The second observer row is
left blank for the partner assigned to work with you. You can of course change the first
observer name as well, but we expect that most of the time you will be one of the observers
doing the game.

This is also where you can change the avatar picture that displays on the home screen.
The default is to choose randomly from among all the available images, but you may
select one in particular to always show if you want.

If you have a request for an additional avatar to add, this is the one "premium" feature
I offer. I don't charge anything for the app, I don't have any adds, and I'm not looking for
any kind of payment. But if you would like to show your support, you can pay to get another
avatar added to the list. Just don't pay me. Instead, you can donate at least $100 to an
Ultimate-related charity "in honor" of UltiObserver. Send me a screen shot of the receipt
along with either a photo or a description of the avatar you would like me to add, and I
will do my best to make one in the same style as these, matching your description or
photo. I'll also list you here as a supporter unless you request to remain anonymous.

Some possible charities you could donate to for this:

* `Ultimate Peace <https://ultimatepeace.networkforgood.com/>`_
* `Ultimate Impact <https://www.ultimate-impact.org/>`_
* `Girls Ultimate Movement (GUM) <https://gum.usaultimate.org/>`_
* `Ultimate Foundation <https://theultimatefoundation.org/>`_

But if you have another one that you would rather support, go ahead and donate
to that. As long as the charity is working to grow or promote Ultimate, I'll accept it.
