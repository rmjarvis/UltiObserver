Installation
============

UltiObserver is currently in Google Play beta testing. To install it, request to
be added to the testing group.

Ping @Mike Jarvis on the observer Discord, or send an email to
mikejarvis17 [at] gmail [dot] com to request an invite.

After you are added to the testing group, use the Google Play testing link or
invitation provided by Mike.

Android Support
---------------

UltiObserver is Android only for now. It is designed for portrait mode and
reasonably current Android phones. The release test matrix includes small
phones, modern Pixel-style phones, large-font settings, dark mode, and selected
foldable/wide-screen checks.

If the app looks wrong or behaves badly on your phone, please report:

* phone model;
* Android version;
* whether you use large fonts, increased display size, dark mode, or
  three-button navigation;
* what you were doing when the problem appeared.


Reporting Problems
------------------

If you are able to, please use the `GitHub Issues`_ page for bug reports, rule
mistakes, confusing observer workflows, crashes, or feature requests. GitHub
issues are preferred because they keep the details in one place and make it
easier to follow up.

If GitHub is inconvenient, ping @Mike Jarvis on the observer Discord or send an
email to mikejarvis17 [at] gmail [dot] com.

.. _GitHub Issues: https://github.com/rmjarvis/UltiObserver/issues
