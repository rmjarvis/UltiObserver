Troubleshooting
===============

Reporting Bugs
--------------

Please report bugs, rule mistakes, confusing observer workflows, crashes, or UI
problems through `GitHub Issues`_.

Good reports include:

* what you expected to happen;
* what actually happened;
* the game situation, if it was rule-related;
* your phone model and Android version;
* whether you use large fonts, increased display size, dark mode, or
  three-button navigation;
* screenshots, if they help explain the problem.

Timing Alerts
-------------

If sound or vibration cues do not fire reliably, check:

* app notification permissions;
* phone sound/vibration mode;
* earbuds or Bluetooth routing;
* battery saver or background restrictions;
* whether the issue happens only when the screen is asleep.

Crashes
-------

UltiObserver includes crash reporting for release builds so crashes can be
found and fixed. If you can reproduce a crash, please still file an issue with
the steps that triggered it.

.. _GitHub Issues: https://github.com/rmjarvis/UltiObserver/issues
